      Import receipt & scoring assumptions
      The historical baseline averages each player's observed DK game scores and actual threshold bonuses over two completed seasons plus current pre-cutoff games. SD and variance describe game-to-game partial scores, not forecast certainty. Goalies use starts only, including pulled starts; wins and overtime losses are observed. Missing short-handed/shootout and goalie offensive components remain flagged. A manual skater minutes adjustment is a capped linear approximation; default is the unadjusted player mean.
      

      Projection Recipe: repeat this analysis
      Run from the DataDawgs checkout with Node.js 22 or newer. This downloads the public source files and runs the tested generator locally; the browser does not execute a refresh.
      node tools/nhl-refresh.cjs --download --as-of 2026-10-13T20:21:00Z --output ../nhl-runs/2026-10-13
      Change the cutoff and use a new output folder for each run. The recipe uses 2025-2027 regular-season history, verified DK scoring, player-specific means and sample variance; goalies use starts. The identity seed is the bundled cohort, so new players and team changes need a reviewed seed update.
      Outputs: projections.csv, model.json, audit.json, backtest.json, comparison.json and workbook-data.json. Raw inputs and their hashes are retained privately in the run folder. Comparison defaults to the bundled version; use --previous path/to/model.json for another run.
